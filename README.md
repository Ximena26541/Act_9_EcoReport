# EcoReport – Territorio más sano

Sistema web para el reporte y seguimiento de problemas ambientales.
Prototipo front-end de la Actividad 9, Aplicaciones Web, Universidad Tecnológica de León (ITIID).

**Docente:** Ma. de Jesús Sánchez Solis

## Tecnologías
- HTML5
- CSS3
- Git y GitHub (control de versiones y GitHub Pages)
- Figma (diseño)

## Vistas del prototipo
- `index.html`: Inicio
- `login.html`: Ingresar
- `registro.html`: Registrarse
- `dashboard.html`: Panel del usuario
- `nuevo-reporte.html`: Registrar un reporte
- `reportes.html`: Consultar reportes

1. Clona el repositorio o descarga el ZIP.
2. Abre `index.html` en el navegador.
